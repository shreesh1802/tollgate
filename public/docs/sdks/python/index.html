Intro

The ProofPay API SDK provides access to the ProofPay API REST APIs.

ProofPay holds community donations in escrow on PayPal and releases each stage payment only when photo evidence passes deterministic checks plus two independent AI reviewers. Plain code makes the decision; a human verifier handles held cases; every step is written to a hash-chained audit log.

Who can call what

RoleHow it identifies itselfCan do
Anyonenothingread projects and the audit log, donate
WorkerX-Worker-Key (returned when the project is created)upload evidence, see the current one-time code
VerifierX-Verifier-Keyread the review queue, approve or reject
OrganiserX-Organizer-Key (only if the server sets one)create projects

Money amounts are decimal strings or numbers in the project's currency (USD). The payee's email address is never returned by any endpoint.

Installation

Add the SDK to your project from its folder, with whichever package manager your project uses. Give each tool a path containing a slash, such as ../proof-pay-api — a bare folder name is looked up on PyPI instead, and resolves to whatever project holds that name there:

Quick Start

Synchronous client

Construct ProofPayApiClient with keyword arguments, and call close() when you are done. Every argument is optional.

Alternatively, scope it — with ProofPayApiClient(...) as client: closes the pool on exit.

Asynchronous client

AsyncProofPayApiClient mirrors ProofPayApiClient with identical method names, and every endpoint method is a coroutine. It takes the same arguments, with some differences — for example, the transport argument is custom_async_http_client.

Alternatively, scope it — async with AsyncProofPayApiClient(...) as client: closes the pool on exit.
