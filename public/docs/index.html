Welcome

The ProofPay API. Pay for community work only after it is proven.

ProofPay holds community donations in escrow on PayPal and releases each stage payment only when photo evidence passes deterministic checks plus two independent AI reviewers. Plain code makes the decision. A human verifier handles held cases, and every step goes into a hash-chained audit log.

This portal, the SDKs and the agent plugin are all generated from one OpenAPI spec, openapi.yaml, which a test keeps in sync with the real server.

How a payment moves

  1. Reserve. A donor creates a donation. PayPal authorizes it (intent: AUTHORIZE), so the money stays in their account.
  2. Prove. The worker uploads a photo for the active stage with that stage's one-time code in it.
  3. Decide. The gate checks for duplicates, location, time and the code, and asks two AI reviewers. It returns RELEASE, RESUBMIT, HOLD or BLOCK.
  4. Release. On RELEASE each donor's exact share is captured and the worker is paid. On HOLD a human verifier decides.
