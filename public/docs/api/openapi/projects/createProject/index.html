Create a project

POST
/api/projects

Stage percentages must add up to 100. Each stage has a time window in which its evidence must be photographed. The response contains the worker key; keep it, it is shown once.

Authorization

OrganizerKey
X-Organizer-Key<token>

Optional key some servers require to create projects.

Short human-readable title.

Lengthlength <= 100

The person who does the work and gets paid.

site*

The site object.

stages*array<>

The stages of the project, in order.

Items1 <= items <= 8
