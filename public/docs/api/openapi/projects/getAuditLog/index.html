Read one project GET

The public view: donations, totals, stages and each stage's submissions. Send `X-Worker-Key` to also receive the one-time code of the active stage.

Reserve a donation on PayPal POST

Creates a PayPal order with intent AUTHORIZE: the money stays in the donor's account and is only reserved. On the sandbox, send the donor to `approveUrl` to approve it; they are then returned to the site and the reservation is confirmed. In mock mode there is no approval step and the donation is confirmed immediately.
